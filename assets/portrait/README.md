# Contact portrait

Place the contact-section portrait here as:

    assets/portrait/elvir-portrait.jpg

The contact section in `index.html` references this path
(`<img src="assets/portrait/elvir-portrait.jpg">`). A black-and-white
grayscale filter and a black frame are applied via CSS, so a normal
colour JPEG is fine. Recommended: a portrait-orientation photo,
roughly 900×1350 or larger, centred on the subject.
